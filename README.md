# Duotone

Maps the image onto a two-colour gradient — the bold poster look used for title cards, drops and lyric moments.

An [azphalt](https://github.com/HereLiesAz/azphalt) extension for
[Guillotine](https://github.com/HereLiesAz/Guillotine).

- **Package id** — `com.hereliesaz.azphalt.duotone`
- **Version** — 1.0.0
- **Kind** — asset (ISF fragment shader)
- **Tags** — `shader`, `stylize`, `duotone`, `gradient-map`, `poster`, `one-click`

## Controls

| Parameter | Label | Range | Default |
| --- | --- | --- | --- |
| `strength` | Strength | 0.0 – 1.0 | 0.85 |
| `hue` | Palette | 0.0 – 1.0 | 0.0 |

## Install

Open **Azphalt Store** inside Guillotine, find *Duotone*, and tap **Install**. The effect is
applied to the selected clip.

To install manually, pack this directory as a `.azp` (a plain ZIP with `manifest.json` at the root)
and side-load it from the store's *Install from file* action.
